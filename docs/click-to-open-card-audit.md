# Click-to-Open Full-Card Audit — 2026-05-12

Walking every card surface in the app to identify which compact-summary
cards should become click-to-open scrollable full cards. Source: full sweep
of every component that imports `Card` from `./ui` plus the inlined
`var(--c-sf)` card patterns. Generated by the Explore agent.

Recommendations use four labels:

- **ALREADY GOOD** — existing UX (route navigation, modal, or inline
  expansion) already serves the click-to-open need.
- **INLINE EXPAND** — should become a click-to-expand-inline card showing
  more without a route or modal change.
- **DEEPER** — modal or route exists but the detail view itself is too
  thin and needs richer content.
- **SKIP** — too small / not useful to expand.

## Priority list (ship in this order)

**Highest value — hidden info coaches check frequently:**

1. **Recent Workouts** (TraineeDetail) — set-by-set + autoregulation scores
2. **OVERDUE PAYMENT** (Dashboard) — payment history + last contact + suggested nudge
3. **Intake submissions** (IntakeView) — full payload inline, no modal friction
4. **Workout history** (ClientPortal) — per-exercise breakdown on athlete side

**Medium value — reduce modal friction:**

5. Exercise library rows — cues + video preview inline
6. Lead cards (WaitlistView) — full context + notes without tab switch
7. Billing table (TraineeDetail) — transaction detail + invoice link

**Already optimal — no change needed:**

Trainee grid cards · chat sessions · PRs · completed workout review queue
