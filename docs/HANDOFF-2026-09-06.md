## The principle now written into the code

Show what is maintained. Compute what can be computed. Nothing else earns a
pixel.

He maintains: availability per athlete per day, practice + contact minutes, what
the weight room did, medical status/onset/RTP, fixtures.
He does not maintain: an RPE per session, a wellness check-in.

So ACWR, readiness, monotony and strain are not "coming soon" — they are another
club's workflow. They appear the moment one session carries an RPE and not
before.

## Traps paid for, do not re-pay

- A probe that clicks tabs by ENGLISH labels measures one tab five times when
  the app is in Hebrew. Click by index. Identical word counts on every line is
  the tell.
- Clearing only `sessionStorage` leaves the previous seat signed in — the
  Supabase session is in `localStorage`.
- Grepping source for an on-screen word fails when CSS uppercases it: the DOM
  said `Update`, the screen said `UPDATE`. Dump the element markup.
- The zone has its OWN language switch (the `עב` button); setting `expo-lang`
  does not move it.
- `git log --format=%h|%s` through node's `execSync` runs in cmd.exe and the
  pipe eats the format. Quote it.
- The Bash tool's heredocs mangle backslashes — write patch scripts with the
  Write tool instead.
- A `file://` screenshot of a PNG hangs the shooter for the full timeout.
- Lazy-loaded images never render in a full-page capture.
- Anything that writes to the store must snapshot first
  (`audit-out/bhbc-state/`) and restore after — the dev server shares the
  production database.
