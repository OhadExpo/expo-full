## 2 · The rules that govern this work

These are not suggestions; breaking one is the failure mode he penalises.

1. **Never build or test on the live site.** Work on a branch; verify locally or
   on a preview. **ASK before any production deploy.**
2. **The dev server shares the PRODUCTION Supabase.** Anything that writes must
   snapshot first and restore after. Trainee-visible tables are off limits for
   trials.
3. **Never invent training or financial data.** Blank beats wrong. An athlete
   with no lift reads "never", not "0 days".
4. **Never use "cure", "diagnose" or "fix"** in UI strings, code comments or
   client-facing text. Use "manage", "load management", "rehab strategy".
5. **Verify before declaring done** — from the real seat, on the real path, with
   observed evidence. A green build is not a working feature.
6. **Never `git add -A` / `git add .`** — stage named paths.
7. Hebrew for athletes and staff is **written, not translated**: masculine
   singular, short, spoken Israeli. Exercise names stay English.
8. Israeli VAT is 18%; VAT-inclusive → pre-VAT multiplier **0.8475**.
9. Marketing (`expo-il/`) and the demo surfaces stay in parity with the product.

## 7 · The principle now encoded

> Show what is maintained. Compute what can be computed. Nothing else earns a
> pixel.

**Maintained:** availability per athlete per day · practice and contact minutes
· what the weight room did · medical status, onset, RTP target · fixtures.
**Not maintained:** RPE per session · wellness check-in.

Therefore ACWR, readiness, monotony and strain stay in the product but appear
**only when their data exists**. `hasLoad` and `hasRead` in `LoadBoard` are that
rule in code.

## 13 · Traps already paid for — do not pay again

1. A probe that clicks tabs by **English labels** measures one tab five times
   when the app is in Hebrew. Click by **index**. Identical word counts on every
   line is the tell.
2. Clearing only `sessionStorage` leaves the previous seat signed in — the
   Supabase session lives in `localStorage`.
3. Grepping source for an on-screen word fails when **CSS uppercases** it: the
   DOM said `Update`, the screen said `UPDATE`. Dump the element markup instead.
4. The club zone has **its own** language switch (the `עב` button). Setting
   `expo-lang` does not move it.
5. `git log --format=%h|%s` through node's `execSync` runs in **cmd.exe** and the
   pipe eats the format. Quote it.
6. The Bash tool's heredocs **mangle backslashes** — write patch scripts with the
   Write tool.
7. A `file://` screenshot of a PNG **hangs** the shooter for the full timeout.
8. **Lazy-loaded images** never render in a full-page capture.
9. `node` resolves `/tmp/...` to `C:\tmp` — use the scratchpad path.
9a. **gviz is lossy on this spreadsheet.** `gviz/tq?tqx=out:csv&sheet=NAME`
    downloads a file, but on a sheet full of merged cells it comes back with
    most cells empty (`headers=0` does not help). Export by `gid` instead.
9b. **A tab click that does not switch tabs is silent.** One run read the same
    gid for all five tabs and overwrote every month with a copy of February.
    The gids are pinned in the downloader now, and it shouts if two months
    come back byte-identical.
10. A script run from outside the repo cannot resolve `puppeteer-core` — keep
    probes inside the repo.
11. The service worker reloads the page after a rebuild: "Attempted to use
    detached Frame" means *retry*, not *broken*.
12. Anything that writes to the store must snapshot to `audit-out/bhbc-state/`
    and restore.
