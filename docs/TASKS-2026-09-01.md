## Phase I — button widths per column (his rule, swept)

share a width. **0 at 1500 and 414 and all six BHBC tabs.** One genuine fix:
the "N previous ▾" control measured 102 / 106 / 110px for 1 / 3 / 10, because

The detector needed three corrections before it stopped crying wolf, each one
a case where a correct screen looked broken:
- **Material.** A bordered box button and an underline text button are
  deliberately different (his control-material rule). Comparing them flagged
  `Duplicate` against `◫ ANALYSIS`.
- **Wrapped rows.** At 390 a wrapping flex row stacks its items on one left
  edge and looks exactly like a column. A real column has one button per row,
  so its members have different parents.
- **Different controls.** Three filter pills named "Unclassified", "Movement"
  and "Primary Muscle" are 157/91/145px because they are different names, not
  one control resizing. Require a label to repeat down the column.

Left as-is and NOT forced: at 390 `/coach/programs` stacks PORTAL (93) and
Delete (52) at one left edge, but only because the action row wraps there -
they are side by side on desktop. Pinning text links to a fixed width would
fight the material rule to satisfy a wrapping artifact.
