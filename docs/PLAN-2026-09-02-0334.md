## One thing to know before reading the diff

`src/BhbcView.jsx` shows **8,282 changed lines**. It is not. The file was the
only CRLF holdout in the repo and the Python patching rewrote it as LF, which
is what `core.autocrlf` stores anyway and what every other source file already
uses. The real change is **23 lines**, verified by diffing both blobs with line
endings stripped:

```
git show origin/master:src/BhbcView.jsx | tr -d '
' > a
git show HEAD:src/BhbcView.jsx          | tr -d '
' > b
diff -u a b
```

Every other touched file was already LF and diffs normally.
