# Lens 6 — QA: what is proven, what is not, and how to prove more

## The gate library

118 scripts matching `scripts/verify-*.mjs`. 34 of them touch BHBC. They are not
unit tests — most drive the real build in the debug Chrome, from a real seat.

### Run these after touching the club zone

```bash
node scripts/verify-bhbc-collapse.mjs                       # every box collapses and stays collapsed
node scripts/verify-pt-no-backend.mjs                       # the zone survives with no network
SEAT=pt W=390 node scripts/verify-mobile-overflow.mjs       # nothing cut off on a phone
SEAT=pt node scripts/verify-no-raw-values.mjs               # no ids, NaN, undefined on screen
LANG_APP=he SEAT=pt node scripts/verify-no-raw-values.mjs   # same, in Hebrew
node scripts/verify-hebrew.mjs                              # the Hebrew voice rules
```

### Run these after touching anything shared (dates, i18n, themes)

```bash
node scripts/verify-athlete-journey.mjs                     # real seat, real path
node scripts/verify-athlete-no-backend.mjs
SEAT=owner node scripts/verify-no-raw-values.mjs            # 23 coach routes
LANG_APP=he SEAT=owner node scripts/verify-no-raw-values.mjs
SEAT=owner W=390 node scripts/verify-mobile-overflow.mjs
node scripts/verify-marketing-site.mjs                      # 54 route/width/language combos
```

All of the above were green at the end of tonight.
`verify-prod-current` is red by design — it goes green only on deploy.

## The rule that makes a gate worth having

**Prove it by breaking the fix.** Three separate versions of one gate once
passed a visibly broken page. A gate that has never failed has proven nothing.

Tonight the handoff audit itself was subjected to this: three false claims were
planted, two were caught, and the one that slipped through exposed a real hole
(the pass checked reality but not the document). Do the same to any gate you add.

## Probes vs gates

`audit-out/probe-*.mjs` are measurements, not gates — they print numbers rather
than passing or failing. The useful ones:

| Probe | Measures |
| --- | --- |
| `probe-bhbc-coverage.mjs` | Latin words per club-zone tab in Hebrew |
| `probe-athlete-coverage.mjs` | the same for the athlete portal |
| `probe-bhbc-english-where.mjs` | dumps the markup of the elements still in English |
| `shot-weightroom.mjs` | screenshots any zone tab, any seat, any language |

## Probe traps that have cost real time

1. **Clicking tabs by English label** measures one tab five times when the app
   is in Hebrew. Click by INDEX. The tell is identical word counts on every line.
2. **`sessionStorage.clear()` alone** leaves the previous seat signed in — the
   Supabase session is in `localStorage`. A "clean athlete run" once measured
   the physio's zone for a full pass.
3. **The zone has its own language switch.** Setting `expo-lang` does not move
   it; you must click the `עב` button.
4. **CSS `text-transform` hides words from grep.** The DOM said `Update`, the
   screen said `UPDATE`, and a source search for UPDATE found nothing.
5. **Measuring straight after a viewport resize** catches an empty frame.
6. **Lazy images never render in a full-page capture.**
7. **A `file://` screenshot of a PNG hangs** the shooter for its whole timeout.
8. **The service worker reloads after a rebuild** — "Attempted to use detached
   Frame" means retry, not broken.

## Not proven

- `audit-out/probe-demo-dates.mjs` carries a header saying it is **not
  trustworthy** and must not be cited as passing. `/demo/athlete` renders
  correctly by hand check; the probe disagrees with that and has not been fixed.
- Hebrew *register* is not machine-checkable. Coverage is.
